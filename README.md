# متابعات شعبة ورشة الديزل — GitHub Pages

نسخة مستقلة جاهزة للنشر العام، أُعدّت بتاريخ 14 سبتمبر 2026 من الموقع التجريبي. النشر على GitHub لم يتم بعد.

## المحتوى

- جميع المتابعات، متابعات غير شرائية، طلبات الشراء، المتابعات المغلقة.
- العربية والإنجليزية، البحث والتصنيفات، آخر تحديث للسجل ولكل بند.
- قراءة ورقتَي «المتابعات» و«المراجع والسجل» من Google Sheets كل 30 ثانية أثناء فتح الصفحة.
- الاحتفاظ بآخر نسخة محمّلة عند تعذر الاتصال، مع بيان حالة الاتصال.
- تضم النسخة المحفوظة 46 متابعة؛ القراءة الناجحة من الشيت تحل محلها في العرض.

## النشر

1. أنشئ مستودعاً في حسابك، مثل `diesel-workshop-followups`. اختر Public لاستخدام GitHub Pages مع GitHub Free.
2. ارفع محتويات هذا المجلد إلى جذر فرع `main`، بحيث يكون `index.html` في الجذر مباشرة، مع جميع ملفات JavaScript وCSS وJSON والصورة والأيقونة.
3. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
4. انتظر اكتمال النشر، وافتح الرابط الذي يظهر في Pages. لا تعدّ عملية النشر مكتملة قبل نجاحها وظهور الرابط.

دليل GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

الملف `.nojekyll` مرفق لتعطيل معالجة Jekyll غير اللازمة لهذا الموقع الثابت.

## تحديث البيانات

تُحدَّث بيانات العمل في ملف Google Sheets المرتبط؛ لا تحتاج تعديلات البيانات إلى نشر الموقع مجدداً. تغييرات تصميم الموقع أو برمجته تحتاج تحديث ملفات المستودع.

معرّفات البنود ثابتة. احتفظ بالمراجع والتواريخ، واستخدم الحالة «مكتمل» فقط بعد تأكيد الإنجاز. «بانتظار الإغلاق» والطلب الملغى لا يعدّان إنجازاً مؤكداً. تحديث المحادثة وحده لا يعدّل الشيت؛ يلزم تنفيذ كتابة ناجحة فيه.
