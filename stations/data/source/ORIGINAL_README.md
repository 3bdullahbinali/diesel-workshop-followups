# فريق صيانة المحطات الخارجية — نسخة المراجعة الأولى
تاريخ إعداد النسخة: 19 سبتمبر 2026
آخر جدول يومي تمت مراجعته: 17 سبتمبر 2026

## البدء
افتح index.html في متصفح حديث. التطبيق مكتفٍ ذاتياً ولا يحتاج مكتبات أو خطوطاً خارجية.
قد تعرض بعض معاينات المرفقات الملف دون تشغيل JavaScript؛ التشغيل المقصود داخل المتصفح.
هذه نسخة أولية محلية لتنظيم الأفكار ومراجعة البيانات، وليست موقعاً منشوراً أو نظام تشغيل جماعياً.

## النطاق والبيانات
- خاص بفريق المحطات الخارجية. لم يتغير موقع ورشة الديزل أو مصدر بياناته.
- 44 متابعة مبدئية: 25 حزمة أعمال، 13 متابعة عامة/مشروع/تنسيق، و6 مسارات طلب شراء.
- 119 نشاطاً يومياً مجمعاً من 8 جداول بين 7 و17 سبتمبر 2026.
- 228 إسناد عمل فردياً جُمعت في الأنشطة؛ ليست 228 مهمة أو 228 ساعة عمل.
- كتابا وارد موثقان مرتبطان بطلبات الشراء؛ لا مستندات كافية لإضافة بقية الوارد أو الصادر أو إثبات إغلاقها.
- 37 متابعة موسومة للتأكيد أو استكمال الدليل، و10 ملاحظات لمراجعة جودة البيانات.
- 42 مرجعاً لمحطة/موقع/جهة عمل؛ هذا ليس تعداداً رسمياً للمحطات. بعضها ورشة أو دعم أقسام أو موقع غير محدد.
- لم تستورد أرقام الهواتف والأعمار وصفوف الإجازات من الجداول.
- بيانات المصادر ومراجع الصفوف محفوظة. المرفقات الأصلية والكتب ليست مضمّنة.
- أسماء المنفذين في الأنشطة لا تعني اعتمادهم ملاكاً دائمين للمتابعات أو أصحاب صلاحيات.

## ما يعمل
البحث والفلاتر، عرض المصادر والأعمال المرتبطة، السجل اليومي، صفحة المحطات، مراجعة البيانات.
إضافة وتعديل المتابعات محلياً، مع تاريخ الإفادة ومرجع التحديث وسجل تعديل محلي.
إضافة وتعديل سجل كتب وارد/صادر وربطه بالمتابعة؛ الصادر يمكن ربطه بكتاب وارد.
اتجاه كتاب مثبت لا يغيّر عند التعديل. الرد يسجل كتاباً آخر، ولا ينشأ أو يرسل عبر تراسل.
إغلاق المتابعة أو الكتاب يتطلب تاريخاً ودليل إغلاق. إغلاق الكتاب لا يغير حالة العمل أو PR.
تصدير JSON كامل، واستيراده، وتصدير CSV للمتابعات والأنشطة. الفلاتر تنطبق على CSV المصدر من الشاشة.
واجهة عربية/إنجليزية، مع إبقاء بيانات المصادر بلغتها الأصلية.

## حدود الحفظ والوصول
التعديلات محفوظة في LocalStorage لهذا المتصفح والأصل فقط إذا سمح المتصفح بذلك.
لا تنتقل تلقائياً إلى جهاز أو مستخدم آخر. التصدير والاستيراد هما وسيلة نقل النسخة المحلية.
عند تعذر LocalStorage يظهر تنبيه؛ يجب تصدير البيانات قبل إغلاق الصفحة.
قد لا تتشارك نسخ HTML المكررة التخزين نفسه. افتح النسخة المعتمدة نفسها، واحتفظ بنسخة JSON بعد التعديل.
لا توجد حسابات موثقة أو صلاحيات أو قاعدة بيانات مشتركة أو سجل تدقيق محمي.
سجل التعديلات المحلي ليس سجل تدقيق غير قابل للتغيير، واسم المحرر غير موثق.
لا يوجد اتصال بتراسل أو SAP أو Google Sheets. أزرار الحفظ لا تكتب إلى أي من هذه الأنظمة.
لا يوجد إرسال بريد أو كتب أو إشعارات تلقائية. لم ينشر هذا التطبيق على خدمة خارجية.

## قواعد المراجعة
1. إنجاز النشاط اليومي لا يساوي إغلاق أمر العمل أو المتابعة أو إثبات جاهزية المضخة.
2. الربط بالمحطة والأصل ونوع العمل، لا برقم أمر العمل وحده؛ توجد أرقام مكررة بين مواقع.
3. لا يفترض انتهاء نشاط لمجرد غيابه من الجدول التالي.
4. تاريخ المصدر لا يستبدل بتاريخ إنشاء النسخة؛ تاريخ التعديل المحلي يحفظ منفصلاً.
5. ملف 16-09-2026 يحمل داخلياً WORK SCHEDULE 15-09-2026 في A1. تاريخ الاسم مستخدم مؤقتاً فقط.
6. الطلبان غير المرقمين للزيوت والشحوم مطلبان منفصلان بحسب السجل السابق، وليسا رقمَي PR منشأين.
7. إرسال/إعداد التقييم لا يثبت اعتماد تراسل أو صدور LPO.
8. لا يدمج مشروع PS-03/PS-6 مع عطل PS-3، ولا أعمال Birdi DN600 مع Bidiya DN450.
9. مهمة الذيد معاينة وتقييم؛ توصيات التقرير ليست أمر إصلاح معتمداً.
10. المهام المساندة لا تنقل ملكية أصول ورشة الديزل إلى سجل المحطات.

## محتويات الحزمة
index.html: التطبيق مع نسخة البيانات الأولية مضمنة.
data.json: نسخة البيانات الأولية المنظمة لاستيرادها داخل التطبيق.
data/followups.csv: المتابعات الـ44.
data/daily_activities.csv: الأنشطة الـ119 ومراجع المصدر والصفوف.
data/tarasel_letters.csv: الكتب المثبتة والربط مع المتابعات.
data/sources.csv: أسماء مصادر الملفات والمحادثات وملاحظاتها.
data/review_findings.csv: الملاحظات العشر.
data/station_references.csv: مراجع المحطات والمواقع، دون ادعاء تعداد رسمي أو جاهزية.
README.md: هذا الدليل.
PRODUCTION_PLAN.md: تنظيم البيانات والصلاحيات المقترح للتشغيل الجماعي.
preview.png: لقطة توضيحية لواجهة سطح المكتب.

تنبيه: CSV وdata.json داخل الحزمة لقطات أولية؛ تعديلها لا يغير تلقائياً البيانات المضمنة في index.html.
لاستيراد JSON محدّث استخدم زر الاستيراد. للتطوير، أعِد تضمين البيانات عند إصدار نسخة جديدة.
ملفات CSV ليست قاعدة تشغيل مشتركة. استيرادها إلى Google Sheets لاحقاً يتطلب بناء الربط ومراجعته.

## الخصوصية والنشر
لا ترفع هذه الحزمة أو البيانات إلى مستودع عام أو صفحة عامة غير محمية.
البيانات مضمنة في HTML وJSON وتقرأ دون تسجيل دخول؛ زر دخول شكلي لن يحميها.
النشر الجماعي يحتاج حماية فعلية للواجهة والبيانات، وصلاحيات من الخادم، وموافقة الجهة على الاستضافة.
لا تتضمن الحزمة كلمات مرور أو مفاتيح API أو اتصالات إلى مصدر الورشة.

## الاختبارات المنفذة
تم فحص JavaScript والتنقل والبحث والفلاتر والعرض على سطح المكتب والهاتف، والإضافة والتعديل،
وربط الكتب، واستقلال إغلاق الكتاب عن المتابعة، ومنع تفسير HTML المدخل كنص برمجي.
اختُبر منطق الحفظ وإعادة تحميل البيانات باستخدام بديل تخزين في بيئة اختبار معزولة؛
بيئة العرض تمنع التنقل إلى أصل محلي حقيقي، لذلك يلزم فحص LocalStorage على متصفح الجهة عند الاعتماد.
لم يجر اختبار تشغيل جماعي أو حسابات أو نشر أو تكامل SAP/تراسل لأن هذه المكونات غير موجودة في النسخة.
