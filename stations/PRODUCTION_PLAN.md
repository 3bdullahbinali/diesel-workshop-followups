# مقترح تنظيم النسخة التشغيلية
هذه خطة تنفيذ مقترحة وليست وصفاً لمكونات مفعّلة.

## الاستقلال
موقع جديد ومصدر بيانات خاص بفريق المحطات الخارجية، لا مجرد فلتر داخل ورشة الديزل.
يمكن اعتماد Google Sheets مستقل كخيار أولي بعد موافقة الجهة، أو قاعدة بيانات معتمدة.
يُمنع استخدام ملف بيانات الورشة أو مفاتيحها أو حساباتها تلقائياً.

## تنظيم الواجهة
لوحة المتابعة، جميع المتابعات، طلبات الشراء.
المتابعات العامة: المشاريع والتنسيق، الأعمال والصيانة، كتب تراسل.
كتب تراسل: الوارد، الصادر، الكتب المغلقة فقط.
السجل اليومي، المحطات والأصول، مراجعة البيانات، المصادر.
تبقى جودة البيانات شاشة مراجعة إدارية، وليست عبئاً يومياً على كل فني.

## نموذج البيانات
Followups: المعرف الثابت، الموضوع، التصنيف، المحطة/الأصل، الحالة، المسؤول، الجهة المنتظر ردها،
الأولوية، الإجراء التالي، الموعد المؤكد، تاريخ الإفادة، تاريخ التعديل، مصدر الإفادة، شرط ودليل الإغلاق.
DailyActivities: معرف النشاط، تاريخ العمل، وصفه، المحطة/الأصل، رقم SAP إذا ثبت، نوع الصيانة،
المنفذون، الإنجاز اليومي، النتيجة النهائية، الحالة المرتبطة، الملف/الصف، ملاحظات التحقق.
PurchaseRequests: رابط متابعة واحد، رقم PR أو معرف احتياج مؤقت، البنود والمواصفات والأكواد،
مرحلة الإجراء، المورد، التقييم واعتماده، LPO، موعد التوريد، الكمية المستلمة والمتبقية، دليل الاستلام.
Correspondence: رقم الكتاب، الاتجاه، التاريخ، الجهة، الموضوع، الإجراء، رد على، المتابعة المرتبطة،
رابط الملف الأصلي، الرد/الإغلاق، دليل الإرسال. لا تخلط اتجاه الكتاب بحالة المتابعة.
StationsAssets: كود وموقع المحطة، الأصل، موديل/سيريال، المهمة، تشغيل/احتياط،
آخر اختبار وتاريخه ونتيجته. الحالة غير المعروفة تبقى غير معروفة.
Sources: مرجع الملف أو الرسالة، تاريخها، روابط معتمدة، مستوى التحقق.
UsersRoles: هويات فعلية وصلاحيات من جهة الخادم.
ChangeLog: من عدّل وماذا ومتى، مع حفظ الحالة السابقة وآلية تعارض التعديلات.

## الأدوار المقترحة — الأسماء تحتاج اعتماداً
المهندس المسؤول: اعتماد النطاق والحالات الحساسة والإغلاق.
منسق الفريق: إدخال المتابعات والطلبات والكتب وتحديثها.
الفنيون/المشرفون: تحديث الأعمال المسندة والنتائج والصور.
مشاهدة للإدارة والمراجعين، مع صلاحيات وصول محدودة.
لا تسند هذه الأدوار تلقائياً من أسماء منفذي الجداول؛ يعتمد الفريق الأسماء والحسابات.

## الاعتماد قبل الربط
تثبيت المتابعات التاريخية الـ37 أو إغلاق ما ثبت إنجازه بدليل.
مطابقة تاريخ ملف 16/9، وأرقام SAP المشتركة، وأنواع الصمامات ووحدات الأغطية.
إكمال بيانات الكتب وأرقام الردود ومرجع كتاب PR10013556 وموضوع وسيم أكرم.
تأكيد أرقام طلبَي الزيوت والشحوم ومرحلة PR10011672 التاريخي.
تثبيت دليل المحطات والأصول والأرقام التسلسلية والفصل بين المواقع المتشابهة.
إدراج المواعيد الحقيقية فقط وعدم توليد تأخير من مواعيد تاريخية لم تعد معتمدة.

## بوابة النشر
استضافة معتمدة وحماية وصول إلى الواجهة والبيانات، لا نشر بيانات حساسة داخل ملفات عامة.
لا تعتبر إخفاء الأزرار أو حسابات داخل JavaScript صلاحيات حقيقية.
تسجيل دخول موثق، تحقق من الصلاحية لكل قراءة وكتابة، نسخ احتياطية، وسجل تغييرات.
اختبار فقد الاتصال، تعارض تعديلات الفريق، الاستلام الجزئي، الإغلاق/إعادة الفتح، وإعادة البيانات.
لا يدّعي الموقع التكامل مع تراسل/SAP قبل توفير API أو وسيلة معتمدة واختبارها.
